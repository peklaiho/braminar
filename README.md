# Braminar remake

Remake of an old DOS text game called Braminar written in modern C.

The original game is included in the [dos](dos) directory.

This remake tries to be faithful to the original game as far as mechanics and texts go. Intentional differences between the classic version and the remake are recorded in [CHANGES.md](CHANGES.md).

For temporary final-assault debugging, run `./braminar --final-assault`. It shows
a level-21 character with end-game supplies, then enters the assault on any key.
It uses normal time-based random seeding. This option is intended for removal
after final-assault reconstruction.
